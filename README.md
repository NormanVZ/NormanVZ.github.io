# Perfil web — Norman Valdez Zamorano

Sitio web inicial, estático y adaptable a móviles, preparado para GitHub Pages y el dominio `normanvaldezzamorano.page`.

## Contenido
- `index.html`: sitio completo (CSS y JavaScript incluidos). No necesita dependencias ni servidor.

## Publicación en GitHub Pages
1. Renombrar este repositorio **`NormanVZ/.github.io`** a **`NormanVZ/NormanVZ.github.io`** desde Settings → General → Repository name.
2. Subir `index.html` a la rama `main` en la raíz del repositorio.
3. Abrir **Settings → Pages → Build and deployment**, elegir **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guardar.
4. Verificar que el sitio abre en `https://NormanVZ.github.io`.
5. Configurar en GitHub Pages el **Custom domain** `normanvaldezzamorano.page`, y añadir los registros A de GitHub en el panel DNS de Name.com. Para el subdominio `www` añadir un CNAME a `NormanVZ.github.io`.
6. Una vez validados los DNS, activar **Enforce HTTPS**.
